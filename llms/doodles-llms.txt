# Doodles

> Doodles, LLC is a Web3-native entertainment and character-IP company built around the
> 10,000-piece Doodles NFT collection launched on Ethereum in 2021. It owns the Emmy-nominated
> animation studio Golden Wolf and ships the Stoodio avatar app, the DOOD token, the Prism
> image model, and DreamNet. **Doodles publishes no public REST API and no developer portal.**
> Its entire machine-facing surface is two first-party open-source Flow-blockchain npm
> libraries and one signed outbound-webhook integration contract on its GitHub organization.

## Integration surface

- [Doodles webhook reference server](https://github.com/Doodles/webhook-example): First-party
  Express/TypeScript receiver for the Doodles outbound webhook contract. Doodles POSTs a JSON
  event to a URL you host; the receiver verifies an `x-signature` header (HMAC-SHA256 over the
  raw body, base64, constant-time compare) and returns the payload with `text` and
  `saveModified` set. Two event types: `request` and `response`.

## Packages

- [@doodlesteam/flooks](https://www.npmjs.com/package/@doodlesteam/flooks): React hooks for the
  Flow blockchain ("wagmi for Flow"). v0.1.0, published 2024-01-05, MIT, beta.
- [@doodlesteam/floo](https://www.npmjs.com/package/@doodlesteam/floo): TypeScript wrapper over
  the Flow Client Library (FCL). v0.1.0, published 2024-01-05, MIT, beta.
